# Python Functions Assignment

This assignment demonstrates how to create and use Python functions, parameters, return values, default parameters, and function calls.

## Files

- `welcome.py` - Contains the `welcome()` function, which creates a welcome message for different names.
- `toolbox.py` - Contains the `double()`, `is_pass()`, and `greet()` functions and tests them with different values.
- `README.md` - Provides information about the assignment, the files, and a short reflection.

## Reflection

The `greet()` function was the hardest to write because I had to understand how the optional `greeting` parameter works and how to combine variables with text using string concatenation. I also learned that `"Hello"` is used automatically when no greeting is provided.
